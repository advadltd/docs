The **Projects** page contains active fieldwork. A Project is a client engagement, and each Project contains one or more tasks such as inspecting an asset or enumerating a customer.

## What you can see

- **Enumerators** see only Projects and tasks assigned directly to them.
- **Supervisors** see Projects and tasks within their assignments.
- **Admins** and the **Super Admin** see the full published Project catalog.

<Note>
  Seeing a Project does not always mean you can collect a record. The **Collect** or **New record** button appears only when you have an active assignment for that task.
</Note>

## Understand task actions

| Action | What it does |
| --- | --- |
| **View records** | Opens the records visible to you for that task |
| **View form** | Previews the questions without starting a new record |
| **Collect** | Starts a new field record for an assigned task |
| **New record** | Starts another record from the task's records page |

## Review existing task records

1. Select **View records** beside a task.
2. Review the reference, collector, status, and submission time.
3. Select a reference to open its answers, workflow dates, and photo evidence.

What appears depends on your role: Enumerators see their own work, Supervisors see permitted assigned-Project work, and administrators see records globally.

## Start a new record

<Steps>
  <Step title="Confirm the correct Project and task">
    Read the names and task description before beginning.
  </Step>
  <Step title="Select Collect or New record">
    The active form opens at its first stage.
  </Step>
  <Step title="Complete the form">
    Follow the stage instructions, complete required questions, and add requested GPS or photo evidence.
  </Step>
  <Step title="Save or submit">
    Save a draft if the work is incomplete. Submit only after reviewing every stage.
  </Step>
</Steps>

## Task variants

Some tasks list variants, such as different equipment or asset types. A variant describes a type of work inside the task; it is not a separate assignment. Follow the form questions to identify the correct variant.

## If work is missing

<AccordionGroup>
  <Accordion title="No Projects are shown">
    Ask an Admin to confirm that your account is active and that at least one published task has been assigned to you.
  </Accordion>

  <Accordion title="A Project appears but a task is missing">
    The task may not be assigned to you, may be excluded from the client Project, or may be inactive. Ask an Admin to review the Project and assignment.
  </Accordion>

  <Accordion title="There is no Collect button">
    You do not have an active assignment for that task, or the assignment has ended. Ask an Admin to check it.
  </Accordion>

  <Accordion title="The form will not open">
    The task may not have an active published form. Record the Project and task names and report them to an Admin.
  </Accordion>
</AccordionGroup>
