---
title: "Glossary"
description: "Simple meanings for words used in the app."
---

| Word | Meaning |
| --- | --- |
| Enumeration | Counting and recording things, here electrical appliances |
| Enumerator | The person who collects the information |
| Appliance | An electrical item such as a fridge, fan or TV |
| Project | One complete counting exercise |
| Task | A piece of work given to you within a project |
| Form | The set of questions you answer |
| Submission | A completed form that has been sent |
| Approval | A supervisor accepting your submission |
| Verification | A second check that a record is correct |
| SOS | An emergency alert for help |
| Assignment | Giving work to a person |
| Export | Downloading your data as a file |
